# كتالوج الخدمات

> الأسعار نطاقات مبدئية مبنية على أسعار سوق حقيقية (`market/PRICING.md`). ميزتنا في التسعير: **فاهمين الفلوس والتشغيل + بنبني بإيدينا + عندنا قوالب جاهزة متجربة**، فنقدر نسلّم أسرع من شركة برمجة وبجودة أعلى من مستقل عادي.
> القاعدة: السعر بيتحدد حسب **القيمة اللي العميل هيوفرها**، والنطاق ده بس نقطة البداية.
> رموز المدة: «أسبوع» = أسبوع شغل بنظام 15 ساعة.

---

## 1) نظام تشغيل وإدارة لنشاطك (حجز · متابعة · تحصيل · تقارير · روابط موبايل)

| | |
|---|---|
| **لمين** | عيادات، سناتر تعليمية، شركات توصيل ونقل، مراكز صيانة، مصانع صغيرة، مكاتب خدمات |
| **الوجع اللي بيحله** | فلوس بتضيع في التحصيل، مواعيد بتتلخبط، شغل على الورق والواتساب، وصاحب الشغل مش شايف أرقامه |
| **العميل بيستلم إيه** | برنامج بالعربي والإنجليزي، ملف تثبيت واحد (أو رابط ويب)، شاشة لكل دور، لينك موبايل للعميل والموظف من غير تطبيق، تقارير يومية، دليل استخدام مصوّر، وتدريب ساعة |
| **المدة** | نسخة أولى شغالة في 2–3 أسابيع (من القوالب الجاهزة)، وتعديلات في 2–4 أسابيع |
| **الدليل** | منصة التوصيل، «حصة» للسناتر، ميزان، مصنع أنظمة الأعمال |
| **مصر** | تأسيس 15,000–60,000 جنيه + اشتراك/صيانة 500–1,500 جنيه في الشهر *(السوق: سناتر 245–1,000، عيادات من 599 جنيه في الشهر، وERPNext للشركات الصغيرة 75–250 ألف)* |
| **الخليج** | 6,000–20,000 ريال للمشروع + صيانة شهرية اختيارية *(أقل من الشركات اللي بتبدأ من 15 ألف ريال)* |
| **عالمي** | 1,500–6,000 دولار للمشروع |

## 2) أتمتة الإكسل والأوفيس والتقارير

| | |
|---|---|
| **لمين** | مكاتب محاسبة، أقسام مالية ومشتريات وموارد بشرية، مصانع، تجار |
| **الوجع** | ساعات كل أسبوع في نسخ ولصق وتقارير متكررة، وأخطاء في الأرقام، والشغل كله واقف على شخص واحد |
| **العميل بيستلم إيه** | أداة تشتغل بضغطة (START): تقرا ملفاتهم، تتأكد من الأرقام (تسوية الإجماليات)، وتطلع التقرير/الداشبورد. ومعاها سجل بكل تشغيل، ودليل، ومن غير ما يحتاجوا يثبتوا بايثون |
| **المدة** | من 3 أيام لأسبوعين لكل سير عمل |
| **الدليل** | xl2ai، محرك أتمتة الإكسل الشامل، xlextract، Files & OCR + 14 سنة خبرة رقابة مالية |
| **مصر** | 3,000–20,000 جنيه لكل سير عمل |
| **الخليج** | 1,500–8,000 ريال |
| **عالمي** | 300–2,500 دولار للمشروع، أو 30–60 دولار في الساعة *(السوق: VBA متقدم 100 دولار، وخبير إكسل عام 12–30)* |

## 3) وكلاء ذكاء اصطناعي وأتمتة سير العمل

| | |
|---|---|
| **لمين** | شركات صغيرة ومتوسطة، أقسام خدمة عملاء ومبيعات وعمليات، شركات أجنبية عايزة أتمتة عن بُعد |
| **الوجع** | مهام بتتكرر بين أنظمة كتير (إيميل، شيت، CRM، ERP)، وردود متأخرة على العملاء، وموظفين بيعملوا شغل آلي |
| **العميل بيستلم إيه** | وكيل/سير عمل شغال (n8n أو بايثون أو MCP)، **بوابة موافقة بشرية** قبل أي إجراء حساس، سجل كامل لكل خطوة، ولوحة متابعة |
| **المدة** | 1–4 أسابيع |
| **الدليل** | wad (وكيل يثبت كل خطوة)، WinSight (خادم MCP)، Economic (الوكلاء يقترحوا والإنسان يقرر)، والمنظومة دي نفسها |
| **مصر** | 10,000–50,000 جنيه |
| **الخليج** | 4,000–20,000 ريال |
| **عالمي** | 40–85 دولار في الساعة، أو 1,000–6,000 دولار للمشروع *(السوق: الوسيط 29.5 دولار، والمميز 85–120. وإحنا معانا خبرة مالية وتشغيلية تبرر أعلى من الوسيط)* |

## 5) فيديوهات إعلانية موشن جرافيك بالكود

| | |
|---|---|
| **لمين** | براندات وصناع محتوى، شركات برمجيات (فيديو للمنتج)، عيادات وسناتر (إعلانات Reels)، شركات بتقدم عرض لإدارتها |
| **الوجع** | الإعلان القصير الكويس غالي وبياخد وقت، وأي تعديل بيبقى مكلف |
| **العميل بيستلم إيه** | فيديو 15–60 ثانية بالمقاس المطلوب (Reels أو 16:9)، موسيقى أصلية من غير مشاكل حقوق، كتابة عربي سليمة، صورة الغلاف، وجولتين تعديل |
| **المدة** | 3–7 أيام للفيديو |
| **الدليل** | استوديو الأفلام بالكود + الشوريل الشخصي (فيلم 6) |
| **مصر** | 30 ثانية: 4,000–12,000 جنيه *(السوق البسيط 3,000–6,000، وإحنا أعلى منه في الجودة)* |
| **الخليج** | 1,500–5,000 ريال |
| **عالمي** | 600–2,000 دولار للـ30 ثانية *(الستوديوهات 1,000–5,000 دولار، والمستقلين المتوسطين 40–90 دولار للثانية)* |

| | |
|---|---|

| **مصر والسعودية** | محتاجة تأكيد من السوق *(مالقيتش مصدر موثوق؛ هتتحدد في أول تقرير سوق أسبوعي)* |

## باقات جاهزة تتباع لأكتر من عميل (منتجات صغيرة)
1. **«حصة» للسناتر:** اشتراك شهري 400–700 جنيه، يعني في نص السوق، بس بيشتغل من غير نت وولي الأمر بيتابع بلينك.
2. **تقرير الإكسل الأسبوعي الجاهز:** للمحاسبين بتسعير ثابت لكل نوع تقرير.
3. **باقة «إعلان Reels شهري»:** 4 فيديوهات قصيرة في الشهر لعيادة أو سنتر.
