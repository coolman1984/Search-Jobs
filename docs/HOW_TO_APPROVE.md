# إزاي توافق على رسالة (من الموبايل، في أقل من دقيقة)

1. افتح تقرير الصبح. هيوصلك إشعار من GitHub بعنوان «📋 فرص اليوم…».
   *(لو المستودع لسه عام، النصوص الكاملة هتلاقيها في Gmail ← المسودات ← «تفاصيل فرص اليوم».)*
2. اقرا المسودة. لو عجبتك، اضغط **«✅ موافق على النص ده بالظبط»**.
3. هتفتحلك صفحة GitHub فيها ملف جاهز. اضغط **Commit changes**، وبعدين **Commit changes** تاني.
   *(لو اللينك فتح تطبيق GitHub ومظهرش الملف، افتحه من المتصفح.)*
4. خلاص كده. في خلال 3 ساعات بالكتير:
   - **لو الرسالة إيميل:** هتلاقيها مسودة جاهزة في Gmail. افتحها واضغط **Send**.
   - **لو منصة زي Upwork أو مستقل أو لينكدإن:** هتلاقي النص والرابط في التقرير. تفتح الرابط وتلزق النص وتقدّم بنفسك.

**بديل يدوي، لو اللينك ما اشتغلش:** من موقع GitHub في المستودع: **Add file ← Create new file**. اكتب الاسم `approvals/<رقم الفرصة>.approve`، والصق البصمة اللي مكتوبة جنب المسودة في التقرير، وبعدين **Commit changes**.

## عايز تعدّل المسودة؟
اكتب ملاحظتك كتعليق على تذكرة التقرير، أو في الشات. هتتعمل مسودة جديدة ليها لينك موافقة جديد.
⚠️ أي تعديل في النص بعد الموافقة **بيلغي الموافقة تلقائيًا**. الموافقة دايمًا على نص واحد بعينه.

## مش عايز الفرصة؟
ماتعملش حاجة. الفرصة هتفضل في القائمة لحد ما تتأرشف لوحدها. ولو عايز تشيلها فورًا، قول «ارفض فرصة F-xxxx» في أي جلسة.

## حد قالك «متتواصلش معايا تاني»؟
قول «سجّل إن فلان مش عايز تواصل». الإيميل بيتسجل كبصمة مشفرة، والمنظومة عمرها ما هتكتب له تاني.

## ليه الطريقة دي آمنة؟
- GitHub بيوقّع أي حاجة إنت بتحفظها من الموقع أو التطبيق **بمفتاحه الخاص**، والمنظومة بتتأكد من التوقيع ده.
- الوكيل الآلي يقدر يكتب ملفات، بس **مستحيل يعمل التوقيع ده**. فمستحيل يوافق بدالك.
- Gmail: المنظومة تقدر تعمل مسودة بس، **ومش تقدر تبعت**. زرار الإرسال في إيدك إنت.
